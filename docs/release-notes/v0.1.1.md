# dsh-2sidebar 0.1.1

[中文](#中文) | [English](#english)

## 中文

### 本次发布

0.1.1 是发布流程版本：首次由 GitHub Actions 的 npm trusted publishing（OIDC）发布，并带 npm provenance；插件行为没有变化。

- npm：`dsh-2sidebar@0.1.1`，对应源码提交 `3c79804`（与 `v0.1.1` tag 一致）。
- 安装：`dsh plugin --profile desktop add dsh-2sidebar`
- 自检：`node --check plugin/client.js`、`node tools/smoke-client.mjs`

## English

### This release

0.1.1 is a release-process release: the first package published by GitHub Actions through npm trusted publishing (OIDC), with npm provenance. No plugin behavior changes.

- npm: `dsh-2sidebar@0.1.1`, source commit `3c79804` (matching the `v0.1.1` tag).
- Install: `dsh plugin --profile desktop add dsh-2sidebar`
- Verify: `node --check plugin/client.js`, `node tools/smoke-client.mjs`
