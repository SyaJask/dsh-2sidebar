# dsh-2sidebar v0.1.1

发布流程版本：首次由 GitHub Actions 的 npm trusted publishing（OIDC）发布，并带 npm provenance；插件行为没有变化。

[English →](#english) | [中文](#中文)

---

## 改进

- **npm 发布改为 GitHub Actions**：tag `v0.1.1` 触发的 workflow 负责发布，不再需要本地 token。
- **带 provenance**：npm 包附带 SLSA provenance，源码提交为 `3c79804`。

## 安装

- npm：`dsh-2sidebar@0.1.1`，对应源码提交 `3c79804`（与 `v0.1.1` tag 一致）。
- `dsh plugin --profile desktop add dsh-2sidebar`
- 升级：保留原有 localStorage 状态，无需额外操作。

完整的技术细节请见 [CHANGELOG](https://github.com/SyaJask/dsh-2sidebar/blob/main/CHANGELOG.md)。

## English

Release-process release: the first package published by GitHub Actions through npm trusted publishing (OIDC), with npm provenance. No plugin behavior changes.

### Changed

- **npm publishing moved to GitHub Actions**: the workflow triggered by tag `v0.1.1` publishes the package; no local token is needed.
- **Provenance**: the npm package ships an SLSA provenance whose source commit is `3c79804`.

### Install

- npm: `dsh-2sidebar@0.1.1`, source commit `3c79804` (matching the `v0.1.1` tag).
- `dsh plugin --profile desktop add dsh-2sidebar`
- Upgrade: existing localStorage state is kept; no extra action is needed.
