# dsh-2sidebar v0.1.4

新增目录树左右位置切换，并清理客户端里不再被观察的状态与兼容兜底；默认布局和既有存储保持不变。

[English →](#english) | [中文](#中文)

---

## 新增

- **左右切换**：预览 header 末尾新增分栏按钮，可把目录树在分栏左侧与右侧之间切换；默认树在左，再次点击切回。
- **记忆与拖拽**：选择存入 `dsh-2sidebar.tree-side`；分隔条拖拽方向、树宽度比例语义和「收起/展开目录」箭头都会跟随当前方向。

## 改进

- **样式表**：整个插件只安装一份样式表（随插件 fiber 卸载），恢复页签在正文尚未挂载时页签标题也保持正确样式。
- **目录收起**：收起目录现在只收起，不再触发一次无意义的目录读取；展开仍会重新读取。
- **死代码清理**：移除未被观察的状态（分栏比例 helper、只写不读的加载更多失败标记、未使用的 `preview.truncated` 文案、冗余的树层级 class/`depth`）、`readBytes` 缺失兜底、header 打开的 fallback 及其 API 探测、`entry.kind` 兜底。
- **文档**：README 修正工作目录来源为框架标准 `useSessions` prop，补充 `dsh-2sidebar.tree-side` 存储键，移除已完成的 roadmap 项。

## 修复

- 恢复页签（正文未挂载）时页签标题样式缺失。
- 收起目录时多余的目录读取请求。

## 安装

- 从 npm：`dsh plugin --profile desktop add dsh-2sidebar`
- 本地开发：`dsh plugin --profile desktop add "link:<repo>"`
- 自检：`node --check client.js`、`npm pack --dry-run`

## 限制

- 仅文本与图片预览；PDF / Office / HTML 用 DSH 原生预览页签。
- 分隔条仍只支持指针拖动，键盘不可操作；「加载更多」失败仍没有行内提示。
- 需要提供 `useSessions` 标准 prop 与 `@deepseek-ai/dsh-client-ui-primitives` 基线的 DSH 版本；客户端 API 已按 0.2.1-rc.5 核对。
- 其余上限与限制见 [README](https://github.com/SyaJask/dsh-2sidebar#readme)。

## English

Adds a switchable tree side and trims unobserved client state and compatibility shims; the default layout and existing persisted values are unchanged.

### Added

- **Left/right switch**: a control at the end of the preview header moves the directory tree between the left and right of the split; the tree starts on the left and a second click switches back.
- **Remembered and drag-aware**: the choice is stored in `dsh-2sidebar.tree-side`; the splitter drag direction, the tree-width ratio, and the hide/show chevrons all follow the current side.

### Changed

- **Stylesheet**: the whole plugin installs one stylesheet for its fiber, so a restored tab's chip title is styled before its body has mounted.
- **Collapsing a directory** now only collapses it instead of issuing a redundant directory read; expanding still re-reads.
- **Dead state removed**: the unused split-ratio helper, the never-read load-more failure flag, the unused `preview.truncated` copy, the redundant tree-level class and `depth` prop, the `readBytes` absence fallback, the header open fallback and its API guards, and the `entry.kind` fallback are gone.
- **Docs**: the README now names the framework's `useSessions` prop as the workspace-root source, documents `dsh-2sidebar.tree-side`, and drops the completed roadmap item.

### Fixed

- The tab chip title keeps its styles when a restored tab's body has not mounted yet.
- Collapsing a directory no longer issues a redundant directory read.

### Install

- From npm: `dsh plugin --profile desktop add dsh-2sidebar`
- Local development: `dsh plugin --profile desktop add "link:<repo>"`
- Verify: `node --check client.js`, `npm pack --dry-run`

### Limitations

- Text and image previews only; use DSH's native preview tabs for PDF / Office / HTML.
- The splitter remains pointer-only (no keyboard operation), and a failed "Load more" still has no inline notice.
- Requires a DSH version with the `useSessions` standard prop and the `@deepseek-ai/dsh-client-ui-primitives` baseline; the client APIs were checked against 0.2.1-rc.5.
- Other caps and limitations: [README](https://github.com/SyaJask/dsh-2sidebar#readme).
