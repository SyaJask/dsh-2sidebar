# dsh-2sidebar v0.1.3

客户端改用框架标准的 `useSessions` 读取会话工作区，并移除不再使用的 `sessions` 服务注入；行为不变。

[English →](#english) | [中文](#中文)

---

## 改进

- **客户端契约对齐**：分栏页签通过框架标准 `useSessions` prop 读取会话工作目录，不再自行订阅 `ctx.sessions`；组件内不再包含订阅机制。
- **清单收敛**：客户端 `inject` 列表移除不再使用的 `sessions` 服务；`dsh.client.inject` 仍保留 `@deepseek-ai/dsh-client-ui-session`，它是 `useSessions` 的提供方。
- **兼容性下限**：`engines.dsh` 的最低版本更新为 `0.2.1-rc.5`，与已验证环境一致。

## 安装

- 从 npm：`dsh plugin --profile desktop add dsh-2sidebar`
- 本地开发：`dsh plugin --profile desktop add "link:<repo>"`
- 自检：`node --check client.js`、`npm pack --dry-run`

## 限制

- 仅文本与图片预览；PDF / Office / HTML 用 DSH 原生预览页签。
- 需要提供 `useSessions` 标准 prop 与 `@deepseek-ai/dsh-client-ui-primitives` 基线的 DSH 版本；客户端 API 已按 0.2.1-rc.5 核对。
- 其余上限与限制见 [README](https://github.com/SyaJask/dsh-2sidebar#readme)。

## English

The client now reads the session workspace through the framework's standard `useSessions` prop and no longer injects the unused `sessions` service; behavior is unchanged.

### Changed

- **Client contract alignment**: the split tab reads the session working directory through the standard `useSessions` prop instead of subscribing to `ctx.sessions` itself; components carry no subscription machinery.
- **Manifest cleanup**: the client `inject` list no longer includes the unused `sessions` service; `dsh.client.inject` keeps `@deepseek-ai/dsh-client-ui-session`, the provider of `useSessions`.
- **Compatibility floor**: `engines.dsh` now starts at `0.2.1-rc.5`, matching the verified environment.

### Install

- From npm: `dsh plugin --profile desktop add dsh-2sidebar`
- Local development: `dsh plugin --profile desktop add "link:<repo>"`
- Verify: `node --check client.js`, `npm pack --dry-run`

### Limitations

- Text and image previews only; use DSH's native preview tabs for PDF / Office / HTML.
- Requires a DSH version with the `useSessions` standard prop and the `@deepseek-ai/dsh-client-ui-primitives` baseline; the client APIs were checked against 0.2.1-rc.5.
- Other caps and limitations: [README](https://github.com/SyaJask/dsh-2sidebar#readme).
